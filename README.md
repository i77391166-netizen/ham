# Хам

Шифрованный чат без серверов и регистрации. Android-приложение на WebView:
весь интерфейс — HTML/CSS/JS, сообщения идут через публичный MQTT-брокер,
ключ выводится из кода комнаты (PBKDF2 + AES-GCM).

## Скачать

Готовый APK: вкладка **Releases** → последний релиз → `app-debug.apk`.

## Что внутри

- **Чаты** — список комнат, превью последнего сообщения, счётчики непрочитанного.
  Клиент подписан на все комнаты сразу, поэтому чужие сообщения тоже приходят.
- **Интерфейс** — телеграм-подобная раскладка: пузыри с группировкой, разделители
  дат, галочки, шторки снизу, круглая кнопка отправки.
- **Стекло** — `backdrop-filter` на шапке, поле ввода, шторках и панели эмодзи,
  цветные пятна на фоне. В «Вид чата» есть переключатель и ползунки размытия
  и прозрачности.
- **Шифрование** — код комнаты = ключ. Отпечаток ключа можно сверить в меню.
- **Шёпот** — сообщение с таймером, сгорает и у обоих.
- **Файлы** — фото/видео/любой файл до 12 МБ, сохраняются в `Download/Хам`.
- **Темы** — 6 пресетов, свои цвета, обои, размер шрифта, скругления.

## Сборка

Собирается в GitHub Actions при пуше в `main`, оттуда же публикуется релиз.

```
app/src/main/assets/index.html   разметка
app/src/main/assets/style.css    стили
app/src/main/assets/app.js       вся логика
app/src/main/assets/mqtt.min.js  mqtt.js (локально, чтобы работало без сети)
```
